This project turns real homelab operating experience into a small, understandable reference for secure remote access.

## What it covers

- Overlay networking and routing peers.
- Split DNS and local-versus-remote request paths.
- Private administration and public application boundaries.
- Storage, backups, and tested recovery.
- Operating useful services on constrained hardware.

## Start here

1. Read the [architecture](/architecture) to understand the traffic and trust boundaries.
2. Use the [quickstart](/quickstart) to preview these docs locally.
3. Review [demo scope](/demo-scope) for runnable behavior and boundaries.

The repository includes a local Compose boundary demo and a synthetic encrypted backup/restore drill, plus architecture and operational lessons. It does not provision a live network, VPN account, router changes, or homelab deployment. All examples use synthetic names, addresses, and data.
